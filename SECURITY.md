# Security Policy

## Supported versions

This project does not currently publish a supported release schedule. Reports are evaluated against the current default branch.

## Reporting a vulnerability

Please use the repository's GitHub private vulnerability reporting when it is available. Until that feature is enabled, or if it is otherwise unavailable, email `qwes8873@gmail.com`. Do not open a public issue or include secrets, credentials, or sensitive learner data in a report.

Include the affected version, a concise reproduction, the expected impact, and any suggested mitigation. Maintainers will acknowledge the report, investigate it, and coordinate disclosure and remediation through the private advisory.

For ordinary defects that do not have security impact, use the public issue tracker linked from `package.json`.
