# PDF study workspace

**Delivery status: design-only.** This directory initializes the requirements for a dedicated PDF tutoring workspace. It does not define or deliver UI, backend, schemas, dependencies, or detailed technical architecture.

The product is a purpose-built learning client and runtime for the repository's existing learning ledger and rule-based tutor policy. Its intended study surface places a PDF on the left and a Hermes conversation on the right while preserving the deterministic, offline core and the explicit GBrain promotion boundary.

## Documents

- [Product requirements](requirements.md) — goals, user journey, functional behavior, learner-model rules, scope, and observable acceptance criteria.

Detailed design may begin only after these requirements are reviewed. The choices intentionally deferred from this phase are listed in the requirements document.
